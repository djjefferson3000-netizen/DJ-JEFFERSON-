## 🚀 วิธีนำขึ้น GitHub และเปิดให้ทุกคนเข้าชมได้ฟรี 100% (GitHub Pages)

### วิธีที่ง่ายและเร็วที่สุด (ผ่านหน้าเว็บ GitHub.com):

1. ไปที่ [GitHub.com](https://github.com/) แล้วกด **"New repository"**
2. ตั้งชื่อว่า `dj-jefferson-portfolio` แล้วเลือกเป็น **Public**
3. แตกไฟล์ `dj-jefferson-portfolio-dist.tar.gz` (ไฟล์สำหรับแสดงผลหน้าเว็บ HTML)
4. ลากไฟล์ทั้งหมดในโฟลเดอร์นั้น (`index.html` และโฟลเดอร์ `assets/`) อัปโหลดขึ้น GitHub
5. ไปที่แท็บ **Settings** ของ Repository > เมนู **Pages** ด้านซ้าย
6. ตรงส่วน **Branch** เลือก `main` หรือ `master` แล้วกด **Save**
7. รอประมาณ 1 นาที จะได้ลิงก์เว็บไซต์ เช่น:
   👉 **`https://<ชื่อผู้ใช้ของคุณ>.github.io/dj-jefferson-portfolio/`**
   (ใครๆ ก็สามารถเปิดดูได้ทันทีตลอด 24 ชั่วโมง โดยไม่ต้องล็อกอินใดๆ)

---

## ⚡ วิธีนำขึ้น Vercel / Netlify (ง่ายสุดๆ เพียง 1 นาที)

1. เข้าเว็บ [vercel.com](https://vercel.com/) หรือ [netlify.com](https://netlify.com/) (ล็อกอินด้วย GitHub หรือ Google)
2. ลากโฟลเดอร์ `dist` ไปวางที่หน้าเว็บ
3. คุณจะได้ลิงก์ เช่น `https://dj-jefferson.vercel.app` ซึ่งสามารถเปิดได้จาก Google ทันที

---

## 💻 วิธี Run โครงการแบบ Local (สำหรับนักพัฒนา)

```bash
# ติดตั้ง dependencies
npm install

# รันเซิร์ฟเวอร์ทดสอบ
npm run dev

# บิลด์โค้ด HTML สำหรับใช้งานจริง
npm run build
```
